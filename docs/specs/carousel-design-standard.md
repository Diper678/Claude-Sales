# Carousel Design Standard — [EMPRESA]

> Definido 2026-04-01 basado en feedback de [APROBADOR] sobre Posts A y B generados en Canva.

## Formato

- **Resolución: 1080x1350px** (portrait/vertical) — NO cuadrado, NO horizontal
- Plataforma principal: Instagram → adaptar a LinkedIn y TikTok después

## Estructura Estándar (7-8 slides)

| Slide | Función | Layout |
|-------|---------|--------|
| 1 | **Hook** | Pregunta provocadora centrada. Ícono S grande como fondo. "[EMPRESA] B2B Sales Automation" abajo. |
| 2 | **Dato impactante** | Número grande en lime (#c5ed36) + frase corta. Minimal. |
| 3 | **Transición/Intro** | Frase que conecta el problema con la solución. Ej: "Cómo automatizar tu departamento de ventas al primer contacto >>>>" |
| 4 | **Feature 1: Generación de Leads** | Título + copy conversacional. Una feature por slide. |
| 5 | **Feature 2: Scoring** | Título + copy conversacional. Una feature por slide. |
| 6 | **Feature 3: Prospección** | Título + copy conversacional. Una feature por slide. |
| 7 | **Summary punch** | Frases cortas apiladas: "Hecho para ti / Todo planificado / Todo inteligente / Responde por ti / No se cansa no duerme" |
| 8 | **CTA** | Llamativo, urgente. "¿Listo para automatizar tus ventas?" + "Agenda demo 15 min" + [TU_DOMINIO] + contacto. NO botón genérico aburrido. |

## Voz del Copy (Estilo [APROBADOR])

- **Directo y conversacional**: "mientras tú te encargas de vender", no "optimiza tu pipeline"
- **Chileno pero profesional**: sin jerga pero cálido
- **Concreto**: "extrae 1000 perfiles de tu mercado ideal" > "genera leads cualificados"
- **Emocional en el cierre**: "No se cansa, no duerme" — humaniza la automatización
- **Cada feature tiene su propia slide completa** — no comprimir 3 en una

## Reglas de Branding

### Ícono S como Fondo (ESTÁNDAR)
- El ícono PNG de [EMPRESA] (S entrelazada lime) va como **fondo** en TODAS las slides
- Posición: centrado, ocupando ~60-70% del slide, detrás del texto
- Opacidad: baja (~15-25%) para que el texto negro sea legible
- Si la slide tiene imagen descriptiva generada, el ícono se omite
- NUNCA poner el ícono en un recuadro pequeño (se corta/borra)

### Footer Constante
- TODAS las slides llevan "[EMPRESA] — B2B Sales Automation" como footer
- Slide 8 (CTA) lleva logo completo prominente

### Colores
- Fondo: #F8F7F5 (warm white)
- Texto principal: #111111 (negro)
- Acento: #c5ed36 (lime) — números destacados, highlights
- Texto secundario: #666666

### Tipografía
- Headlines: Sans-serif grotesque bold (Sharp Grotesk o equivalente Canva)
- Body: Sans-serif clean (Source Sans 3 o equivalente Canva)
- Texto centrado en slide 1, alineación flexible en demás

## Imágenes Generadas (Nanobanana/AI)

### Cuándo usar
- Slides 3-4 cuando el contenido se beneficia de una visual (gráficas, diagramas, iconografía)
- NO en slide 1 (hook es texto puro + ícono fondo)
- NO en slide 5 (CTA es texto puro)

### Prompt Estándar para Nanobanana

```
Genera una ilustración minimalista para un carrusel de Instagram de una empresa B2B de automatización de ventas.

ESTILO OBLIGATORIO:
- Fondo: warm white (#F8F7F5) — DEBE coincidir exactamente
- Colores: negro (#111111) para líneas, lime (#c5ed36) para acentos
- Estilo: flat design, geométrico, líneas limpias
- NO gradientes complejos, NO 3D, NO realismo
- Inspiración: Stripe, Linear, Vercel — tech B2B premium
- Aspect ratio: 1:1 (1080x1080px)

CONTENIDO: [describir lo que debe mostrar la imagen]

EJEMPLOS DE CONTENIDO QUE FUNCIONA:
- Gráfica ascendente con barras lime (para slides de resultados)
- Diagrama de flujo simple (para slides de proceso)
- Iconos geométricos en grid (para slides de features)
- Reloj/velocímetro minimalista (para slides de velocidad/tiempo)
```

### Lo que NO funciona
- Imágenes con fondo que no coincide con #F8F7F5
- Ilustraciones demasiado detalladas o realistas
- Imágenes que compiten con el texto por atención
